# Sinergia 2 — Sede Anisacate

Sitio y sistema de gestión (cuotas, pagos, rutinas) de Sinergia | Centro de Entrenamiento, sede Anisacate (Ruta 5 km 34).

- Todo el sitio es `index.html` (HTML + CSS + JS, imágenes embebidas).
- Firebase propio: proyecto `sinergia-sede-2` (Auth email/contraseña + Firestore). Reglas en `firestore.rules`.
- Es una copia independiente de Sinergia La Bolsa (`sinergiagym/Sinergia-gym`). Cambios en uno NO afectan al otro.
- Publicado con GitHub Pages desde la rama `main`.
- Esta sede NO registra asistencias en la app: los ingresos se controlan con el molinete. El QR que genera el admin (link `?al=`) es solo para que el alumno entre a su cuenta.
